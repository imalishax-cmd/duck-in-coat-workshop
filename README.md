# duck-in-coat-workshop

Небольшой локальный сайт «Утка в пальто»: одностраничная витрина бренда. Посетитель видит предложение бренда, нажимает «Подобрать образ» и получает одну из двух заранее заданных рекомендаций.

## Статус

Пока есть только документация. `index.html` появится при выполнении задач из [PLAN.md](PLAN.md).

## Запуск

Сборка, сервер и установка зависимостей не нужны. Когда `index.html` будет создан, откройте его в браузере двойным щелчком или командой:

```sh
open index.html
```

## Документы

- [spec.md](spec.md): сценарий, ограничения и критерии готовности (DoD).
- [PLAN.md](PLAN.md): задачи по порядку.
- [AGENTS.md](AGENTS.md): правила работы агентов в репозитории.
