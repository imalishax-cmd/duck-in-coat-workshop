# Спецификация: сайт «Утка в пальто»

## Цель

Показать посетителю предложение бренда и дать ему рекомендацию образа одним нажатием.

## Сценарий

1. Посетитель открывает страницу и видит название бренда и его предложение.
2. Посетитель нажимает кнопку «Подобрать образ».
3. На странице появляется одна из двух заранее заданных рекомендаций.

## Ограничения

- Один файл `index.html` со встроенными HTML, CSS и JavaScript.
- Без framework, backend, базы данных и API.
- Без секретов и внешних изображений.
- Страница работает при открытии файла локально, без сервера и сети.

## Вне рамок

Корзина, оплата, формы, аккаунты, сохранение данных между посещениями, деплой.

## Критерии готовности (DoD)

1. При открытии `index.html` из файловой системы страница отображается без сервера и сборки.
2. На первом экране видны название «Утка в пальто», предложение бренда и кнопка «Подобрать образ»; рекомендации до нажатия нет.
3. После нажатия кнопки на странице появляется ровно одна рекомендация, без перезагрузки.
4. При повторных нажатиях показывается только одна рекомендация за раз, и её текст всегда совпадает с одним из двух заранее заданных вариантов; за несколько нажатий можно увидеть оба.
5. На вкладке Network в DevTools при загрузке и нажатии кнопки нет внешних запросов, а в репозитории из кода сайта есть только `index.html`.
6. В консоли браузера нет ошибок при загрузке и после нажатий.
7. При ширине окна 360 px текст читается, кнопка нажимается и нет горизонтальной прокрутки.
