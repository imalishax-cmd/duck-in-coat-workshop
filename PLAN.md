# План

Задачи выполняются по одной и по порядку, см. [AGENTS.md](AGENTS.md). Номера DoD относятся к [spec.md](spec.md).

- [ ] **1. Каркас страницы.** Создать `index.html` с названием бренда, предложением и кнопкой «Подобрать образ».
  Проверка: открыть файл в браузере, убедиться, что всё видно и рекомендации нет (DoD 1, 2).

- [ ] **2. Стили.** Добавить встроенный CSS и адаптивную вёрстку, без внешних изображений и шрифтов.
  Проверка: посмотреть страницу на обычной ширине и на 360 px (DoD 7).

- [ ] **3. Рекомендации.** Задать два варианта образа и показывать один из них по нажатию кнопки.
  Проверка: нажать кнопку несколько раз, увидеть оба варианта и только один за раз (DoD 3, 4).

- [ ] **4. Итоговая проверка.** Пройти все DoD в чистой вкладке и исправить найденное.
  Проверка: Network без внешних запросов, консоль без ошибок, DoD 1–7 выполнены (DoD 5, 6).
